# ProjectFlow

Aplicación web full stack para gestión de proyectos, tareas, usuarios y comunicación en tiempo real para equipos de desarrollo de software.

## Tecnologías

- React + Vite
- Node.js
- Express
- SQLite
- Socket.io
- Axios
- Git + GitHub

## Funcionalidades

- Dashboard con métricas generales.
- CRUD de usuarios.
- CRUD de proyectos.
- CRUD de tareas.
- Asignación de tareas a usuarios y proyectos.
- Chat en tiempo real con Socket.io.
- Diseño responsivo tipo dashboard.

## Instalación

### Back-End

```bash
cd backend
npm install
npm run dev
```

### Front-End

```bash
cd frontend
npm install
npm run dev
```

### Servidor

http://localhost:5001

### Base de datos

Se utilizó SQLite porque es ligera, fácil de configurar y adecuada para una primera fase académica. No requiere un servidor externo y permite persistir usuarios, proyectos, tareas y mensajes.
