# Diseño UI/UX - ProjectFlow

## Objetivo del diseño

ProjectFlow tendrá una interfaz moderna, clara y responsiva para facilitar la gestión de proyectos, tareas, usuarios y comunicación en tiempo real dentro de un equipo de desarrollo de software.

## Pantallas principales

1. Dashboard
2. Proyectos
3. Tareas
4. Usuarios
5. Chat en tiempo real

## Layout general

La aplicación utilizará un diseño tipo dashboard con:

- Menú lateral izquierdo.
- Encabezado superior.
- Tarjetas de estadísticas.
- Tablas para listar datos.
- Formularios para crear registros.
- Panel de chat en tiempo real.

## Estructura visual

Sidebar:

- Dashboard
- Proyectos
- Tareas
- Usuarios
- Chat

Header:

- Nombre de la aplicación: ProjectFlow
- Descripción breve del módulo actual

Contenido:

- Tarjetas informativas
- Formularios
- Tablas
- Mensajes en tiempo real
